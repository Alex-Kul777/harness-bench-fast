# Issue tracker

## Where issues live

GitHub Issues on the hub repo **`Alex-Kul777/openclaw-workspace`**. The fork
`Alex-Kul777/harness-bench-fast` has its own Issues disabled, so all tracking
issues for this repo are filed in the hub.

Create one with:

```
gh issue create --repo Alex-Kul777/openclaw-workspace --title "..." --body "..."
```

## Rules

- One issue per work item; link the Workboard card id in the body.
- When the issue implements an OpenSpec change, reference the change id.
- **PRs as a request surface: off** (flip here if external PRs should enter triage).

## Consumers

`to-spec`, `to-tickets` and `triage` read from and write to this tracker.
