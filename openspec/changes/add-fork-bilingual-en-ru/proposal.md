# add-fork-bilingual-en-ru

## Why

Форк-слой (FORK.md, `docs/fork.html` и вложенные страницы/таблицы) — русскоязычный по
умолчанию, но публичная страница GitHub Pages читается и англоязычной аудиторией
(upstream-контрибьюторы, внешние читатели). Сейчас англоязычный читатель видит только RU
и не имеет переключателя. Нужна двуязычность EN+RU, не ломающая merge-guard'ы форка и
канонические (английские) колонки таблиц.

## What Changes

- **Каталог локалей** `scripts/fork_i18n.py` — ключи сообщений `{ru, en}` + helper с
  fallback на дефолтную локаль.
- **Генераторы принимают локаль.** `build_fork_home.py` и `build_fork_pages.py` дополнительно
  выпускают EN-зеркала: `docs/fork.en.html`, `docs/fork-sample.en.html`,
  `docs/fork-run-<id>.en.html`, `docs/fork-detail-<stem>.en.html`.
- **Markdown-зеркала.** `FORK.en.md` и `docs/fork-results.en.md` (RU-файлы остаются дефолтом).
- **Языковой переключатель** RU⇄EN в навигации обеих версий; сохраняет текущий таб/якорь.
- **Канонические заголовки таблиц остаются английскими** в обеих локалях (совместимо с
  `--lint`); локализуются только прозаические подписи, заметки и статусы.
- **Проверка паритета локалей**: `--check` для RU и EN; наборы строк данных совпадают.

## Capabilities

### New Capabilities

- `localization`: политика языков форк-слоя (RU-дефолт + EN-зеркало), каталог сообщений,
  языковой переключатель и паритет данных между локалями.

### Modified Capabilities

- `result-reporting`: страницы результатов форка и вложенные таблицы публикуются в двух
  локалях (RU-дефолт + EN-зеркало) при сохранении канонических английских колонок.

## Impact

- Публичные `docs/` (`fork.html`, `fork-sample.html`, `fork-run-*.html`, `fork-detail-*.html`),
  `FORK.md`, `docs/fork-results.md`, три генератора, CI-проверки.
- Прогоны и данные (`results/*.json`, `docs/*-results.json`) **не меняются**.
- **Out of scope:** перевод методологии `README.md` и upstream-строк; перевод данных JSON и
  сообщений задач/верификатора; локали сверх `en`/`ru`; автоматический языковой детект.
